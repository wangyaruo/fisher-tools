# 翘嘴与鲌类习性

翘嘴红鲌（翘嘴）及青梢、蒙古鲌等近缘鲌类，属于典型的中上层掠食鱼，以小鱼、小虾为主食，依靠视觉主动追捕，与鲤鲫的「守食」逻辑完全不同。

## 水层与活动

鲌类多活动于水体中上层开阔区，但巡游层随饵鱼与光线变化：

- **晨昏与夜间**：上浮至浅水、近岸追逐饵鱼，是路亚与活饵钓的高峰。
- **白昼强光**：下潜到较深、有结构或背阴的水层，仍在中上层范围。
- **流水口、下风口**：饵鱼聚集处，鲌类常在此形成捕食带。

## 与气象条件的关系

| 条件 | 鲌类表现 |
| --- | --- |
| 晨昏弱光 | 活跃、群体捕食 |
| 夜间 | 近岸追饵积极 |
| 闷热低氧 | 活性下降 |
| 风浪起、溶氧高 | 捕食窗口增强 |

鲌类的捕食高度依赖**视觉与饵鱼分布**，因此光线弱、饵鱼上浮的时段最有利。闷热缺氧时连掠食鱼也会停口。

## 觅食机制

翘嘴靠**追击**而非守候：发现饵鱼群后高速冲刺吞食，常在水面激起炸水。由此决定两点：

- **饵的动态优先于味型**：活饵、缓沉或抽动拟饵比静态死饵有效得多。
- **节奏**：模拟受伤小鱼的不规则抽动、停顿，更容易触发攻击。

体型越大越偏向**清晨、夜间与深水大饵**；小个体翘嘴白天也常在浅水追饵。

## 常见误区

1. **用死饵等口**：鲌类是追逐者，静态饵的中鱼率远低于动态饵。
2. **忽视窗口期**：白天强光下硬钓往往空军，错在时段而非钓法。
3. **一味远投**：近岸草边、入水口常有小饵鱼群，大翘嘴也会在夜间靠边，并非越远越好。

> 结语：钓鲌类要顺着**饵鱼与光线**走，把动态饵投到捕食带，并优先利用晨昏与夜间的窗口。
