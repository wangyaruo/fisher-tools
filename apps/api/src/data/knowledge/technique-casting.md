# 抛竿落点与压水线

## 一、为什么落点要准

打窝是为了把鱼聚到一处，钩饵若总落在不远处，就脱离了窝子的味型与饵料浓度范围，诱钓不一致，聚来的鱼吃不到钩。

**落点集中是「诱钓一体」的基础**。专业作钓通常要求每竿落点控制在碗口大小范围内，长期偏差会让窝子发散、鱼群分散。尤其静水小漂时，落点散一寸，钩距窝心可能就偏出一截。

## 二、几种抛竿手法

| 手法 | 适用场景 | 要点 |
| --- | --- | --- |
| 荡抛 | 无风、近距离、追求轻柔 | 竿尖轻弹，饵靠惯性荡入，落水声小 |
| 侧抛 | 有侧风、需避开障碍物 | 饵从身体一侧划弧送出，借风修正 |
| 平抛 | 顶风、远投 | 低平挥竿减小迎风面，靠初速送远 |

手法选择以「能稳定落到同一点」为准，不必追求花式。**姿势与发力每次尽量一致，是准度的根本来源**。

## 三、压水线的原理与做法

压水线指把浮漂到竿尖之间那段漂在水面的「风线」压入水中。

不压水线时，这段线漂在水面，风一吹就带动浮漂位移，产生假信号，也把钩饵悄悄拖离窝心。压线是借助水的阻力固定风线：抛竿后竿尖先不入水，等浮漂站立、风线拉直，将竿尖稍插入水并轻回拉，使风线没入，再前送回正竿尖。这样风线贴着水面下走，受风影响大幅减小，漂目更稳。

## 四、影响准度的因素

- **风**：侧风顶风都偏移落点，需提前修正或换手法。
- **线长与饵重**：线越长惯性越大越难控，饵太散抛程中脱落也会偏。
- **姿势一致性**：每次站位、挥竿幅度不同，落点必然散。
- **视线参照**：选远处固定物作瞄准点，比凭感觉更稳。

可先空竿练落点再带饵，逐步把偏差收小。**准度是练出来的，不是一次调出来的**。

## 五、常见误区

1. **抛竿不压水线**：风线漂在水面，浮漂随波位移，误判鱼口还怪漂不准。
2. **一味抛满竿**：追求远却让风线绷直难压，且鱼中钩后无缓冲余地易拔河。
3. **落点散乱不纠正**：每竿差一点，长期偏离窝心，聚鱼效果大打折扣。
4. **重饵不补抛**：饵在飞行中脱落，看似落点准，实际钩上已空。

> 结语：落点准决定鱼在不在窝里，压水线决定漂稳不稳，二者做实了，读漂才可信。
