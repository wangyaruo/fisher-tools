# 季节与水层选择

## 一、主线是水温，不是季节名称

「春钓浅、夏钓深」是结论，原因在水温：

- 水的比热大，升降温都慢于空气。**气温的剧烈变化不会立刻传导到水下。**
- 表层水随气温变化快，深层水滞后明显。深水水库与海域的滞后可达数日。
- 鱼是变温动物，会主动游向**温度最接近自身适宜区**的水层。

所以换季时不要只看日历，要看**最近几天的气温走势**。一次强冷空气过后，浅水会先降温，鱼会退回深水两三天才重新靠边。

## 二、各季节的落点

| 季节 | 鱼主要在哪 | 原因 |
| --- | --- | --- |
| 早春 | 向阳浅滩、水草边 | 浅水升温快，浮游生物与昆虫先活跃 |
| 仲春至初夏 | 浅水与深浅交界 | 水温全面适宜，鱼沿岸觅食产卵 |
| 盛夏 | 深水、阴凉、进水口、增氧处 | 表层过热、溶氧低，鱼避热趋氧 |
| 秋季 | 由深转浅，秋末回深 | 水温回落，鱼需大量进食越冬 |
| 冬季 | 深水、背风、向阳 | 水温稳定且相对最高 |

## 三、把水层当成一个可调参数

很多钓友只调饵料不调水层，其实水层的优先级更高：

1. **先定水层**：用搜索钓法从底往上试，每隔 30 厘米停一会儿，直到出现稳定信号。
2. **再定饵料状态**：确认鱼层后，再决定用雾化快的还是留鱼久的。
3. **最后调味型**：低温偏腥、高温偏香。

**判断鱼离底的信号**：

- 浮漂在饵下落途中出现接口
- 到底后长时间无口，但窝点有鱼星
- 出现「蹭线」——浮漂缓慢下沉或无规律晃动但不中鱼

出现以上任一信号，都应考虑钓离底，而不是继续等。

## 四、昼夜节律

一日之内也有类似「季节」的迁移：

- **黎明前后**：浅水溶氧回升，鱼由深向浅移动，是第一个窗口期。
- **正午**：夏季鱼退入深水或阴凉处，是明显的低谷。
- **傍晚至入夜**：溶氧与光照再次变得有利，是第二个窗口期。

这也是本站在总览页给出**晨昏黄金时段**与**日月活跃时段**的原因：它们标识的是这两个窗口的具体时间点，而非笼统的「早晚好钓」。

> 结论：水层是一天之内可以反复调整的变量，先找鱼层，再谈饵料。
