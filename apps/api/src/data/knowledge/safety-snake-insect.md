# 蛇虫与蜱虫防护

野钓多在草丛、石缝、湿地等环境，正好是蛇、蜱虫、蜂类活跃的区域。这类风险的特点是**局部发作、容易被忽视**，但处置不当会造成远超鱼获的损失。

## 一、蛇的识别与风险

蛇在气温 18℃ 以上开始活跃，清晨与黄昏觅食频繁，雨天前后尤为多见。它们偏好草丛边缘、倒木下、石块缝隙与岸边浅水交界处。

**识别风险**在于多数蛇不主动攻击人，伤人多发生在垂钓者踩踏、伸手进草丛或搬动石块时惊扰了蛇。夜间与视线不良时风险显著上升。

## 二、蛇伤预防

- **穿高帮鞋与长裤**，不要赤脚或穿凉鞋进入草丛。
- **打草惊蛇**：下竿前用竿梢轻拨前方草丛与石堆，给蛇留出逃离时间。
- **不徒手搬石、不把手伸进视线不及的洞缝**。
- 钓位选在相对开阔、地面平整处，减少蛇的藏身空间。

## 三、蜂类的预防与处置

蜂类多在食物、甜味饮料附近聚集，挥竿时易误触蜂巢。

- **不喷香水、不遗留含糖饮料**，饵料与食物封口存放。
- 发现蜂群盘旋时**静止慢退**，不要挥舞衣物或跑动，跑动会诱发追击。
- 被蛰后尽快离开现场至封闭空间，记录被蛰数量与部位，**出现呼吸困难、面唇肿胀等全身反应应立即就医**。

## 四、蜱虫的识别与预防

蜱虫多附着于草尖，等待宿主经过时攀附，常见于腿部、腰部与颈部。其危险在于叮咬后长时间吸附，可能传播疾病。

| 风险环节 | 表现 | 应对 |
| --- | --- | --- |
| 草丛穿行 | 蜱虫攀附裤脚 | 穿浅色长裤并将裤脚扎入袜口 |
| 叮咬吸附 | 无痛感，不易察觉 | 返程后全身检查，重点看腋下、腹股沟 |
| 错误拔除 | 口器残留致感染 | 用尖头镊贴近皮肤夹住头部垂直拔出 |

## 五、蛇伤现场处置

被蛇咬伤后的核心原则是**减缓毒素扩散并尽快就医**，现场不采血、不切开、不冰敷、不饮酒。

- **保持冷静、减少活动**，让伤肢低于心脏水平，避免加速循环。
- 用清水冲洗伤口，去除表面毒液，记录蛇的大致形态（不鼓励追打）。
- **移除伤肢上的戒指、手镯等束缚物**，以防肿胀后缺血。
- 用绷带在伤口近心端做加压包扎固定，但**不要用细绳紧勒阻断血流**，随后尽快前往有抗蛇毒血清的医院。

> 底线：蛇虫蜂蜱可防可控，被咬蛰后最危险的动作是盲目自救。拍照识别、减少活动、尽快就医三项即可。
