# 打结与连接强度

## 一、线组上的连接节点

一套线组有若干必须连接的节点，每个节点都是潜在的薄弱处：

- **主线与竿稍**：通常用活扣连接，便于快速拆装，又不易滑脱。
- **主线与八字环**：用合理的线结锁死，防止受力时回转松脱。
- **子线与八字环、与钩**：分别打结，要求既牢又小，不伤线、不挡信号。

**核心结论**：连接强度不是看线多粗，而是看每个结打得好不好。一个松结比细一号线更危险。

## 二、八字环的作用

八字环（转环）连接主线和子线，它有两个价值：

- **释放旋转**：鱼挣扎或线组受水流影响会扭劲，八字环转动把扭力卸掉，避免子线打卷。
- **缓冲与更换**：子线可单独更换，主线与漂保住。

**做法**：选转动顺滑、环体不过小的八字环。太小的环在受力大时会卡死不转，失去意义。

## 三、打结的通用要领

无论哪种结，以下原则通用：

- **结要打紧、打顺**：结体歪扭、叠压不均，受力点集中在一处，容易从那里断。
- **蘸水收紧**：收紧前让线湿润，减少摩擦生热对线表面的损伤。
- **留足线头**：线头太短容易回抽松脱，留一小段并修剪整齐。
- **定期更换受力结**：反复受力的结会疲劳，尤其连接八字环和竿稍处的线。

## 四、常见误区

1. **结越紧越牢**：暴力收紧会烫伤线、留下暗伤，反而更早断。收紧要稳，不要猛拽。
2. **一个结通用所有节点**：竿稍活扣、八字环锁结、子线钩结受力方式不同，硬套一种结会增加风险。
3. **子线打结处可重复使用**：打过结又解开的线，结区纤维已受伤，再次受力先从这里断，应剪掉重打。

> 结语：打结是线组里最考验细节的环节，结打对了，细线也能扛住意外的力；结打错了，粗线也白搭。
