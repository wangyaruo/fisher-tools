# 台钓调漂与双铅钓法

## 一、先理解原理：调目与钓目

调漂的本质是**设定浮漂的剩余浮力**。

- **找底**：重铅到底，上推浮漂至水面露出目数，得到水深。
- **调目**：半水挂饵前修剪铅皮，让浮漂露出目标目数（如调 6 目）。
- **钓目**：挂饵找底后浮漂露出的目数（如钓 2 目）。

调目与钓目的差值决定灵敏度：

| 状态 | 灵敏度 | 适用 |
| --- | --- | --- |
| 钓目 < 调目 | 高（子线绷直，一钩触底一钩悬浮） | 鱼口轻、冬季、静水 |
| 钓目 ≈ 调目 | 中（双钩到底，子线微弯） | 常规出钓 |
| 钓目 > 调目 | 低（双钩躺底，子线弯曲） | 杂鱼多、走水、大鱼 |

**记忆要点**：钓目越小越灵，越大越钝。调低钓高是钝，调高钓低是灵。

## 二、双铅钓法

双铅指在主线上设两个铅皮座，通常上铅大、下铅小。

**它解决的问题**：单铅在流水中会被冲走，需要加大铅重才能稳住，但铅重一大灵敏度就没了，鱼口看不出来。双铅把「配重」与「灵敏度」拆成两件事：

- **上铅**：承担大部分配重，负责把线组锚定在钓点。
- **下铅**：只承担少量配重，决定入口阻力。它可以在主线上滑动，鱼吸饵时只需克服下铅的惯性。

**适用场景**：走水的河道、有风浪的大水面、需要远投且水深较大的场合。

**调整顺序**：先调上铅到目标目数，再逐渐加下铅直到线组在流水中能稳住。下铅越轻，入口越顺，但抗流能力越弱，需要按实际水流反复试。

## 三、常见误区

1. **只看调目不看饵重**：调 4 目钓 2 目，如果饵重不足 2 目，下钩可能离底。台钓的灵敏度是调目、钓目、饵重三者共同决定的。
2. **浮漂越贵越灵**：吃铅量匹配线组与水深才是关键。深水用小吃铅的漂，信号会被水线本身消耗掉。
3. **走水时一味加重铅**：加重铅提升的是稳定性，牺牲的是信号。改双铅或用跑铅才是正解。

> 结论：调漂没有通用答案，先问「今天要的是灵敏度还是稳定性」，再决定怎么调。
