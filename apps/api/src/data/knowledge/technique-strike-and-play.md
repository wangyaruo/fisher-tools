# 提竿时机与遛鱼

## 一、漂相识别与提竿时机

读懂漂相是提竿的前提。不同动作对应鱼不同的就饵阶段，时机错了要么空竿要么跑鱼：

| 漂相 | 含义 | 提竿时机 |
| --- | --- | --- |
| 顿口 | 浮漂有力下挫半目到数目，多为吸饵入口 | 下挫瞬间提，宁早勿拖 |
| 顶漂 | 浮漂缓缓上顶，常见于鲫鱼送漂 | 上顶停顿或加速时提 |
| 黑漂 | 浮漂整支没入，多为大鱼或抢食 | 没入后略顿即提，防深吞 |
| 接口 | 浮漂未到底就被拉走，鱼离底截饵 | 见拉动即刻提 |

**核心原则**：信号有「加速」或「停顿」的异常变化时才提，匀速起伏多为风浪或水流假信号。

## 二、刺鱼的动作要领

刺鱼靠的是短促的「寸劲」，不是大幅甩竿。

手腕带动小臂快速上抖，让钩尖在鱼唇上刺出一个稳固的着位点，行程通常只有十几厘米。幅度过大容易把鱼嘴撕豁或把钩拉出，幅度过小则刺不透。提竿方向略偏上即可，不必把竿甩过头顶。**刺中后的第一反应是迅速感知鱼的大小与走向**，再决定是直飞还是进入遛鱼。

## 三、遛鱼的原理

遛鱼的本质是**用竿身的弹性把鱼的冲力卸掉**，而不是用蛮力把鱼拉上来。

鱼发力外窜时，应放低竿尖、顺势送线，让竿子弯成弧线吸收冲击，待鱼力竭再收回。始终保持线组绷直但不死拉，线与竿夹角过小会失去缓冲，夹角过大则容易拔河断线。鱼往哪窜就朝反方向侧引，反复消耗其体力，切忌生拉硬拽对着干。

## 四、控鱼与抄鱼

鱼力道减弱、不再深钻时进入控鱼阶段。把鱼头牵引出水面，让它呛水翻白，此时才具备抄获条件。

抄网应从鱼头方向迎着鱼头插入，顺势向前一兜将鱼抄入，不可从鱼尾方向追抄，那样鱼受惊会再次发力。鱼体过大时先稳住再分次收拢，**抄网入水要提前布好，等鱼到位一次成功**，反复挑逗只会给鱼脱钩机会。

## 五、常见误区

1. **见漂就提**：把风浪起伏当鱼口，空竿率高还容易惊窝。
2. **生拉硬拽**：第一时间竖竿死拉，线组失去缓冲，轻则跑鱼重则断线。
3. **过早抄鱼**：鱼未翻白就下网，鱼受惊暴冲，前功尽弃。
4. **刺鱼过猛**：大幅甩竿把鱼唇撕豁，看似中鱼实则很快脱钩。

> 结语：提竿讲的是读准信号与寸劲刺稳，遛鱼讲的是以柔卸力，二者分寸对了，大鱼也能稳稳入护。
