# 梅雨与汛期作钓

进入梅雨季与汛期后，钓鱼的核心矛盾从「水温」切换为「溶氧与水位」。持续阴雨、低气压、水位暴涨暴跌，是这个时段的三条主线。

## 低气压与溶氧

- 连绵阴雨天光照弱、气压低，水体溶氧持续走低，鱼活性差、容易离底上浮。
- 此时钓位优先选**溶氧相对高**的位置：进水口、下风口、流水河段，而不是传统的深水老钓位。
- 饵料适当加腥，钓法上从钓底向钓离底、钓浮调整。

## 涨水的红利与代价

- **红利**：水位上涨淹没岸边草地、农田，带来大量食物，鱼会大胆靠到近岸浅水——「涨水钓边」正是此意。新淹没的草滩、洄湾是黄金钓位。
- **代价**：水位不稳，今天的好位明天可能就没顶或退干；水体浑浊时鱼靠嗅觉觅食，味型宜浓、宜腥。
- **退水期**则相反，鱼退回深槽，近岸迅速变难钓。

## 雨后初晴是窗口

持续阴雨后的第一个放晴日，常常是整个汛期里最好的出钓窗口：气压回升、溶氧改善，鱼集中补偿性开口。这个窗口值得在日历上提前圈出来。

## 安全红线

- 山洪与滑坡：山区溪涧在暴雨后可在极短时间内暴涨，河谷、低洼钓位雨天一律不去。
- 湿滑的堤岸与泥坡是摔伤高发区，穿防滑鞋，钓位不要贴近陡坎。
- 雷电：空旷水面与举竿的组合极其危险，听到雷声立即收竿撤离。
- 上游水库泄洪前通常有预警，关注当地发布，水位异常上涨时先撤人再收东西。

> 结论：汛期作钓的口诀是「溶氧选位、涨水钓边、初晴抢口、暴雨收竿」。渔获的红利与安全的红线在这个季节是同一枚硬币的两面。
