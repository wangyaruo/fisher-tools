# 极端天气的撤离判断

水边是极端天气的高危场所：开阔无遮挡、地面湿滑、撤离路径易被水淹。多数事故发生在「再钓一会儿」的犹豫里。撤离的关键不是跑得快，而是**决定得早**。

## 一、识别三类天气的预警信号

| 天气类型 | 早期信号 | 危险后果 |
| --- | --- | --- |
| 雷暴 | 远处雷声、气压骤降鱼口暴增、乌云压顶 | 接闪、瞬间强降雨 |
| 大风 | 旗帜持续平展、浪形变乱、树枝剧烈摇摆 | 掀翻浮具、抛竿失控 |
| 暴雨 | 天色快速变暗、风向骤转、远处雨幕 | 视线归零、水位暴涨 |

**信号出现即开始准备**，不要等天气到头顶才行动。

## 二、雷暴的撤离

- 碳素竿是极佳接闪器，**听到第一声雷即收竿**，竿体平放远离身体。
- 撤离至**封闭车辆或建筑内**，不躲孤立大树、不躲滩涂临时伞下。
- 雷暴常伴短时强风与雨，路面湿滑，行走放慢、避开陡坎临水侧。

## 三、大风的撤离

- 关注**持续风力而非阵风峰值**，当风力使站立与持竿明显吃力时应收竿。
- 浮具、帐篷、饵箱等**先固定或收起**，避免被风卷走伤人。
- 大风叠加涌浪时，礁石与防波堤区域危险性陡增，优先撤往内陆高处。

## 四、暴雨与洪水的撤离

- 暴雨使**视线与脚下滑度同时恶化**，且山区、河道水位可能在短时间内暴涨。
- 不在**河道中央、泄洪道、桥下低洼处**停留，这些位置撤退窗口极短。
- 撤离路线选**地势渐高、远离水岸**的道路，不抄近路穿越漫水路段。

## 五、建立个人撤离阈值

把模糊的「天气不好」变成可执行的标准：

- **设定触发条件**：如闻雷即走、风力难站立即走、雨幕及眼前即走。
- **提前告知同伴阈值**，做到一致行动，不因一人想再钓而拖住全员。
- **预留时间余量**，从决定到完全离开钓点需要路程，信号一现就动身。
- 手机保持电量与救援电话，撤离中遇险能立即呼救。

> 底线：撤离没有「太早」这回事。天气信号出现就走，鱼和装备都能再来，人回不来不行。
