# 天然谷物饵

商品饵讲究雾化与味型，天然谷物饵走的是另一条路：**味道淡、状态硬、留鱼久**。杂鱼啃不动、大鱼不警惕，这是它在野钓大物时长期不衰的原因。

## 三种最常用的谷物饵

- **玉米**：嫩玉米直接挂钩，钓草鱼、鳊鱼、翘嘴效果直接；老玉米煮熟或发酵后钓鲤鱼、青鱼，酸香与酒香对大个体鱼有稳定吸引力。
- **麦粒**：酒泡或发酵后挂钩，主攻鲫鱼、鲤鱼。粒小耐啃，杂鱼多的水域比商品饵省心得多。
- **红薯**：烤至七八分熟、切小块挂钩，甜香软糯，鲤鱼、草鱼都爱。注意太软易脱钩，宁硬勿烂。

## 使用要点

- **窝饵同源**：用什么打窝就用什么钓。玉米窝配玉米钓，让鱼在熟悉的食性里放松警惕，这是谷物饵最核心的原则。
- **挂钩露尖**：钩尖微露更利于刺鱼；完全埋进饵里适合鱼口狡猾、反复试探的老鱼。
- **守钓节奏**：天然饵雾化慢、诱鱼慢，换饵频率以半小时到一小时计，频繁提竿反而惊窝。
- **抗杂鱼**：杂鱼疯狂的水域，挂麦粒或玉米往往立竿见影——不是饵更香，是小鱼啃不动。

## 发酵的做法

老玉米或麦粒煮到开花，沥干后加少量曲酒与糖，密封发酵三至七天，微酸带酒香即成。发酵时间越长酸度越高，夏季肥水中效果最好；酸到刺鼻就是用过头了。

> 结论：谷物饵的本质是「用低警惕换大鱼」。窝饵同源、钩尖微露、耐得住守，三件事情做到位，性价比没有对手。
