# 荤饵：蚯蚓、红虫与活饵

## 一、活饵为什么在低温更有效

水温低时，多数鱼的代谢与嗅觉灵敏度下降，对植物性香味的响应变弱，但对**蛋白质含量高、有动态与腥味的活饵**仍会摄食。蚯蚓、红虫的体液与蠕动提供了化学与物理双重信号，这是商品饵在冬春难以完全替代的。

## 二、蚯蚓与红虫的适用差异

| 维度 | 蚯蚓 | 红虫 |
| --- | --- | --- |
| 适温 | 全年可用，春秋更稳 | 低温、冰钓优势明显 |
| 目标鱼 | 鲫、鲤、鲶等广普 | 鲫、鳊及冷水鱼 |
| 挂钩 | 整条或段，穿钩简单 | 单条或扎把，需技巧 |
| 留存 | 皮韧耐小鱼 | 易破、易死、需保鲜 |

**关键结论**：低温小水面与冰钓，红虫通常比蚯蚓更对路；杂鱼多、需要耐咬时，蚯蚓整条穿挂更稳。

## 三、穿钩与保鲜

- 蚯蚓宜从头部下方穿入、留出尾段蠕动，但不宜露钩尖过多以免挡口；大钩可挂半段或整条。
- 红虫可单挂、可扎把（用皮筋或线捆成小束），扎把在流水与低温中诱鱼更集中。
- 保鲜靠低温与湿润：红虫用湿布覆盖放阴凉处，避免泡水久放导致死亡发臭。

判断新鲜度：活饵体色鲜亮、有蠕动即为可用；色暗、发黏、无味则诱效大减。

## 四、常见误区

1. **活饵不需状态**：其实穿法、露出长度都影响入口，露钩过多易空竿。
2. **红虫万能**：高温季节红虫易死、招杂鱼，效果未必优于蚯蚓或商品饵。
3. **反复用死饵**：死红虫、断蚯蚓诱效与动态信号都丢失，应及时更换。

> 结语：活饵的价值在于「动」与「腥」，低温与轻口时是务实的选择，但也要随季节与鱼情判断，不必全年依赖。
