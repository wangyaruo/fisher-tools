# 路亚入门

路亚（Lure）用仿生拟饵模仿小鱼、虾、虫的动作，引诱掠食性鱼主动攻击。它与饵料钓的根本区别是：**人找鱼**，而不是打窝等鱼。因此读水、找结构比调饵重要得多。

## 装备三件套

- **竿**：直柄配纺车轮、枪柄配水滴轮，入门建议直柄纺车组合，上手快、炸线少。调性选 M（中调）泛用性最好。
- **线**：主线用 PE 编织线（无延展、传导清晰），前面必须接一段碳线或尼龙**前导线**，提供耐磨与缓冲。
- **轮**：纺车轮 2000 至 2500 型是淡水泛用区间，速比不用刻意追高。

## 常见拟饵与用法

- **米诺**：模拟小鱼泳姿，匀收即可，主攻中上层（翘嘴、鲈鱼）。
- **亮片**：靠反光与摆动诱鱼，便宜耐用，适合新手与搜索陌生水域。
- **软虫**：配铅头钩或德州钓组，跳底、慢拖，主攻底层（鳜鱼、鲈鱼）。
- **VIB**：震颤下沉快，适合远投与深水搜索。

## 基本手法

入门只需先练两种：**匀速收线**（米诺、亮片）与**收停结合**（收两圈、停一拍，模拟受伤小鱼）。多数咬口发生在「停」的瞬间，扬竿宁慢勿急。

## 注意事项

- 拟饵普遍用三本钩，摘钩务必用控鱼器与钳子，徒手摘钩是新手最常见的受伤。
- 咬口集中在早晚与阴天，正午烈日下往往徒劳——与出钓窗口的思路一致。
- 路亚对象鱼多为掠食性鱼种，钓获放流是主流共识；当地法规对钓法、水域另有限制的，以官方发布为准。

> 结论：先用「纺车轮 + M 调竿 + PE 加前导 + 亮片与米诺」这套最便宜的组合练抛投与读水，拟饵泳姿做对了，鱼自然会出现。
