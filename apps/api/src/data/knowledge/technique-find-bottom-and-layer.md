# 找底与找鱼层

## 一、为什么必须先找底

找底的目的不是测一个水深数字，而是**确认钩饵在水底的真实状态**。

自然水域的水底极少平整，常见有起伏、斜坡、乱石与淤泥。若只按浮漂目数推算深度，钩饵可能悬在斜坡上方、陷入酱层或托在石尖上，这些都会让鱼无法正常就饵。同样调目下，钩离底与钩触底、躺底，对应的入口阻力与信号差别极大，因此找底是调钓成立的前提。

## 二、两种找底的做法

| 方法 | 操作要点 | 解决的问题 |
| --- | --- | --- |
| 粗找底 | 重铅裹主线，抛入后上推浮漂至露出目数，得到大致水深 | 快速确定水有多深，避免修剪铅皮时反复试 |
| 精确找底 | 调好漂后挂饵，上推浮漂至钓目稳定出现，确认下钩触底 | 排除水底不平和淤泥带来的虚深，确定钩饵位置 |

**关键判断**：挂饵后浮漂目数稳定且与预期钓目一致，说明钩已到底；若目数远高于预期，多半是钩未触底或坠悬空。

## 三、为什么要找鱼层

鱼并非总在底层。水温、溶氧、气压与光照变化，都会让鱼在某个水层聚集：清晨与夜间溶氧较高时上层活跃，午后底层趋稳；闷热低压时鱼常离底上浮。不同鱼种也有固有水层习惯，鲫鱼鲤鱼偏底，鲢鳙鳊鱼多在中上层。

**找鱼层的意义**在于把钩饵送到鱼嘴边，而非守着空水层等鱼。底层长时间无口时，先怀疑鱼不在底，而不是先换饵。

## 四、试探鱼层的方法

从底开始，每次将浮漂下捋十到二十厘米，等于把钩饵抬高一截，逐层向上试探：

- 若某层出现截口、半水接口或浮漂未到钓目就被拉动，说明鱼在该层。
- 每次调整只改一个变量，便于判断是水深问题还是味型问题。
- 中上层有口后，可小幅回找，确认鱼层厚度，避免反复大幅拉漂。

节奏上宜先稳定钓底，确有离底迹象再动漂，不宜一开始就频繁拉层，否则会打乱窝子与读漂判断。

## 五、常见误区

1. **以调目代替找底**：调漂时半水是悬空的，不挂饵找底就下竿，钩可能并未触底，信号自然对不上。
2. **一次找底定终身**：水底不平或走水带动线组位移后，钩饵位置已变，应随作钓过程复校。
3. **忽视酱层**：淤泥厚的水域，重饵会陷入表层软泥，鱼闻得到吃不到，需减轻饵重或钓离底。

> 结语：找底定的是钩的位置，找鱼层定的是鱼的位置，二者都确认，钓组才真正落在鱼口上。
