# 黄颡鱼习性

黄颡鱼（俗称黄辣丁、昂刺鱼、嘎牙子）是分布极广的小型肉食性鱼。它白天躲在石缝、草边、障碍里几乎不动，夜间出来觅食，是最典型的**夜钓对象鱼**之一。

## 活动规律

- **昼伏夜出**：日落后活性陡增，20 时至次日凌晨是主窗口；夏夜浅滩常能连竿。
- **白天也有机会**：阴雨天、水体浑浊时光线弱，黄颡白天同样开口——浑水钓黄颡是老经验。
- **栖息结构**：静水或缓流的石堆、倒树、草洞、桥墩边，有障碍就有它。

## 饵料与钓组

- **饵料**：蚯蚓是万能首选，鸡肝、猪肝、小虾等浓腥荤饵效果同样稳定。味型越腥越好，不需要状态讲究。
- **钓法**：串钩抛竿守钓、手竿钓底均可。它吃钩凶狠，漂相多为大幅度的下沉或拖走。
- **防吞深**：黄颡吞钩常常深及喉咙，**摘钩器是必备品**，没有它摘钩会非常狼狈。

## 毒刺务必当心

黄颡背鳍与两侧胸鳍各有一根硬刺，刺基带毒腺，被扎后剧痛、肿胀，痛感可持续数小时。摘钩时用毛巾包住鱼身或用控鱼器固定，让三根刺贴在可控方向，再从容下钩。

> 结论：夏夜 + 浅滩障碍边 + 蚯蚓，是钓黄颡的标准答案。收获它的前提是尊重那三根刺——毛巾与摘钩器带好，再谈渔获。
