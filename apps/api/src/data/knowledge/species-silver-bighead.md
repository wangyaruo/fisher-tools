# 鲢鳙习性

鲢鱼（白鲢）与鳙鱼（花鲢、胖头）同属滤食性鱼类，靠鳃耙过滤水中的悬浮颗粒，几乎不吞食颗粒状固态饵，因此钓法围绕「雾化」展开。

## 水层与活动

鲢鳙主要活动于水体中上层，但水层并非固定：

- **温度高**：上层水温合适时贴近中上层，常在水面下 0.5 至 1.5 米。
- **温度低**：下潜到更深的水层，有时接近底层。
- **溶氧低**：会上浮到表层甚至在水面张口呼吸，此时多数已不开口。

## 与气象条件的关系

鲢鳙对溶氧极为敏感，对水温要求高于鲤鱼、鲫鱼。

| 条件 | 表现 |
| --- | --- |
| 水温 20 至 30℃ | 活性高，是主要垂钓窗口 |
| 水温低于 15℃ | 活性明显下降，摄食减弱 |
| 高溶氧、微风 | 中上层巡游活跃 |
| 闷热低氧 | 浮头、不开口 |

鲢鳙偏好**高溶氧与较高水温**的环境，因此夏季晴朗、有微风的水域表现最好；连续阴雨、水体缺氧时基本无口。

## 觅食机制

鲢鳙的进食靠「吸入—过滤」：将含有悬浮颗粒的水连同雾化饵一起吸入，用鳃耙留住食物。因此作钓的核心是**制造并维持一个雾化带**，让鱼在过滤雾化颗粒时误将钩吸入。

- **饵料状态**：需高雾化、轻质，能在目标水层缓慢散开。
- **鲢与鳙的差异**：白鲢偏好酸臭、发酵味，鳙鱼（花鲢）偏好腥香、臭味更重，但二者对雾化的依赖一致。
- **频率**：需保持一定的抛竿与补窝频率，断雾后鱼群容易散开。

## 常见误区

1. **把饵料搓死**：过硬过黏的饵几乎不雾化，鲢鳙无从滤食，等于空钩。
2. **钓层固定不变**：水温变化时鱼层会上下移动，应从小层差开始逐层搜索。
3. **误以为鲢鳙吃颗粒**：它不主动吞颗粒，钩被滤入是被动的，钩型过大或包裹过实都会降低中鱼率。

> 结语：钓鲢鳙的本质是**养好一个雾化带**，并把钩稳定在鱼群滤食的水层里。
