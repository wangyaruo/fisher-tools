# 草鱼习性

草鱼是生长快、体型大的中上层鱼类，幼鱼阶段偏荤食，成鱼后以植物性食料为主，对水温与溶氧的要求高于鲤鲫。

## 水层与迁移

草鱼并非始终在中上层，水层随温度与食物变动明显：

- **高温季节**：活跃于中上层，常在近岸水草区、芦苇边巡航，取食水面或水下植物。
- **气温下降**：下潜至中下层与深水，活动减弱。
- **夜间与清晨**：常靠近浅滩与草边觅食，是岸钓草鱼的高频时段。

## 与气象条件的关系

| 条件 | 草鱼表现 | 应对 |
| --- | --- | --- |
| 水温 25 至 32℃ | 活性高峰 | 主攻季节 |
| 闷热低氧 | 上浮、厌食 | 改钓流水或深潭 |
| 雨后水位涨、岸草入水 | 靠边疯狂觅食 | 钓近岸草边 |
| 大风浪天 | 避浪、向背风区聚集 | 钓下风或背风湾 |

草鱼是**喜温怕低氧**的鱼，高温并非障碍，缺氧才是。夏季闷热天它比鲤鲫更早停口，而雨后水草、岸草被淹入水时是难得的窗口。

## 觅食偏好

草鱼的食性随生长阶段切换：

- **幼鱼**：偏食浮游动物、水生昆虫等荤食。
- **成鱼**：以草、芦苇嫩叶、谷物、薯类为主，对嫩草尖、玉米、发酵草味接受度高。

它偏好**鲜嫩、带汁、微发酵**的植物性饵料；老化、粗硬的草茎兴趣低。作钓时可用草捆打窝，靠持续的草腥味聚鱼。

## 观漂要点

草鱼吃口有力，典型的入口信号是**浮漂大幅下沉（黑漂）或斜拉**，源于它含饵后转身下潜。也有先缓送、再猛顿的过程，尤其在钓底草饵时。

> 结语：草鱼的核心变量是**水温与溶氧**，把握高温、高氧、有新鲜草料的时段与钓点，比纠结配方更重要。
