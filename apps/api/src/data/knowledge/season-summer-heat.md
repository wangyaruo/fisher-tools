# 夏季高温期

## 一、高温下的溶氧危机

夏季鱼口差，主因往往不是「热」，而是**溶氧随温度升高而下降**。气体在水中的溶解度与温度负相关：水温越高，能承载的氧气越少。同时高温促使藻类与微生物代谢加快，进一步消耗水中氧气，形成夜间缺氧、清晨回升的日循环。

鱼的呼吸需求在高温下反而上升（代谢快），供给却下降，于是鱼会优先游向**溶氧相对充足的区域**，摄食被压缩到缺氧缓解的短暂窗口。这就是夏季「难钓」的物理根源。

## 二、降温与增氧的优先落点

围绕「氧」字，夏季可优先选择以下位置：

| 落点 | 增氧机理 | 适用情形 |
| --- | --- | --- |
| 深水层 | 底层水温较低、溶氧较稳定 | 静水大水面正午 |
| 阴凉处 | 遮光降温、减缓藻类耗氧 | 树荫、桥下、建筑物背阴 |
| 进水口 | 流动水带入大气氧、带走热量 | 雨后或水库放水时 |
| 下风口 | 风浪打破水面、促进气体交换 | 有持续风的天气 |

**判断缺氧的现场信号**：鱼浮头、水面频繁炸水、长时间无口但窝中有鱼星，都提示溶氧不足，应主动换点或等窗口。

## 三、时段选择的底层逻辑

夏季的时段优劣，本质是溶氧的时段分布，而非单纯光照：

- **凌晨至日出前**：植物夜间耗氧结束、水面复氧开始，是相对较好的时段。
- **正午**：表层过热、溶氧低，多数鱼退入深水或阴凉处，是低谷。
- **夜间**：气温下降、溶氧回升，夜钓在夏季往往优于白天。

所以**夏季应把出钓重心放在清晨与夜间**，而非传统意义上的「全天守候」。

## 四、常见误区

1. **只看温度不看氧**：以为避热就行，却忽略静水正午底层也可能缺氧，结果换到深水仍无口。
2. **雨后必爆护的错觉**：小雨能增氧，但雷暴雨后水体浑浊、温跃层被打乱，鱼口常先乱后稳，未必立刻好钓。
3. **一味打重窝**：高温下窝料易发酵坏水、进一步耗氧，重窝反而适得其反，应少量多次。

> 结语：夏季钓鱼的钥匙是溶氧，围绕增氧选点、把精力放在清晨与夜间，比全天死守更有效。
