# 鱼钩刺伤与现场急救

鱼钩刺伤是垂钓现场最频发的事故，成因多是抛投失误、解钩分心、挂底强拉回弹。正确处理的目标是**避免二次损伤、控制出血、预防感染**，而非追求当场完美取钩。

## 一、识别伤情的风险等级

| 情形 | 风险点 | 现场判断 |
| --- | --- | --- |
| 钩尖浅刺、无倒刺挂住 | 出血与感染 | 可谨慎自行处理 |
| 倒刺已入肉 | 硬拔撕裂组织 | 不强行拔出 |
| 刺入眼睑、关节、神经血管区 | 结构损伤 | 立即就医，不自行取 |
| 深部刺伤且脏污 | 破伤风风险 | 清洗后尽快就医 |

**带倒刺的钩绝不要硬拔**，倒刺会钩住组织，强拉造成更大创口与出血。

## 二、预防刺伤

- **抛投前确认后方与侧方无人**，喊「抛竿」后再动作。
- 解钩用控鱼器或毛巾包裹鱼身，**手不放在钩的可能弹回路径上**。
- 挂底时**剪线而非猛拉回弹**，回弹的鱼钩速度极快。
- 随身携带尖嘴钳与消毒用品，小伤当场处理，避免带伤继续操作。

## 三、浅刺无倒刺的处置

- 用流动清水冲洗伤口，去除泥沙与鱼黏液。
- 碘伏消毒，**顺刺入方向轻轻退出**钩体，不旋转拧扯。
- 止血后覆盖无菌敷料，观察有无红肿渗液，必要时就医。

## 四、带倒刺刺入的处置

当倒刺已钩住、无法直接退出时，现场可采用「推穿剪钩」法降低损伤：

- **保持镇定，不要慌乱拉扯**，固定伤肢防止二次刺入。
- 若钩尖与倒刺距皮肤较浅，可推动钩体使钩尖从另一侧穿出皮肤。
- **用钳剪断露出端的钩柄或倒刺**，再从原路退回钩体，减小创口。
- 此法仅用于体表可操作部位，**面部、手足关节、深部刺伤不尝试**，直接加压止血并就医。

## 五、出血控制与感染预防

- 出血时用**干净敷料持续加压**止血，不反复掀开查看。
- 四肢出血且加压无效时，在伤口近心端用止血带，**记录绑扎时间**并尽快送医。
- 所有刺伤均存在破伤风与细菌感染风险，**脏污或较深的伤口应尽快就医**评估是否需要处置。
- 不涂抹来源不明的草药或粉末，保持伤口清洁干燥。

> 底线：鱼钩刺伤不可怕，可怕的是硬拔与拖延。控血、不强行取钩、尽快就医，三步做到即无大碍。
