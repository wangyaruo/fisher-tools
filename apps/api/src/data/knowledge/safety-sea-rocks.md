# 矶钓与礁石安全

矶钓是垂钓中风险等级最高的一种。脚下是湿滑、有落差、会被浪覆盖的礁石，身后是开放海域。事故往往不是因为鱼大，而是因为**一波没算到的涌浪**。

## 一、识别礁石环境的风险

- **涌浪拍击**：看似平静的海面会周期性涌来大浪，瞬间淹没低处礁石并卷走人员。
- **湿滑与落差**：藻类覆盖的礁石极滑，浪蚀洞穴与断崖肉眼难辨。
- **退路切断**：涨潮时海水从两侧合围，原本的登陆点变成无法通行的激浪带。
- **孤立**：离岸礁石一旦落水，救援到达前只能靠自身装备自保。

## 二、装备硬性要求

- **救生衣必须全程穿着**，不是下水才穿。选择带救生哨与反光条的专用款。
- **防滑钉鞋**是礁石行走的刚需，普通鞋底在藻类上几乎无摩擦力。
- 佩戴**头盔**，防范被浪抛起后头部撞击礁石或被坠物砸中。
- 随身带**救生绳与可漂浮的抄网袋**，遇险时先自浮再互救。

## 三、看懂浪况再下竿

| 信号 | 含义 | 处置 |
| --- | --- | --- |
| 长周期涌浪 | 间隔数分钟的大浪，平静期易误判 | 保持高位，预留撤离时间 |
| 白沫持续上涌 | 浪已覆盖落脚点 | 立即后撤至安全高度 |
| 潮水快速上涨 | 退路变窄 | 提前转移，不等鱼口 |
| 风力骤增 | 浪高与乱流加剧 | 收竿撤离 |

看涌浪要看**周期与方向**，不只看浪高。在两次大浪之间的平静期下竿，并把每次大浪当作会更高的那次来防。

## 四、站位与撤离路线

- **只在浪打不到的高位礁石作钓**，脚下留足缓冲，不坐在最低一级。
- 出发前**确认两条以上撤离路线**，并实地走一遍，不要在涨潮后才发现无路可退。
- 与同伴**保持视线与呼喊可达的距离**，分散时约定集合点。
- 不背对大海整理装备，余光始终留一部分观察来浪。

## 五、落水与被卷处置

- 落水后**保持仰面、双脚朝浪的方向**，用脚抵挡礁石而非用手，减少撞击伤。
- 脱困后先评估自身状态，再考虑救助同伴，**不盲目下水**增加第二个遇险者。
- 被浪卷走时保存体力顺流漂浮，待浪隙向岸边或同伴抛来的漂浮物靠近。

> 底线：矶钓者死于「再钓一条」的侥幸。救生衣穿好、浪况看准、退路留好，三者缺一就上岸。
