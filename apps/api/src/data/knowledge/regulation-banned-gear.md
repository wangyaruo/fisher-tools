# 禁用渔具与渔法

## 一、为何要限制渔具与渔法

渔具与渔法直接决定捕捞对资源的影响程度。某些方式不论捕获量多少，都会对水体生态造成不可逆伤害，或对非目标物种、幼体形成「通杀」式打击。因此监管并非只管「捕了多少」，更管**用什么方式捕**。对休闲垂钓而言，理解这条界线，是为了不把娱乐行为滑向破坏性捕捞。

## 二、普遍被禁止的渔法

从各地制度的共性看，**电鱼、毒鱼、炸鱼等以杀伤方式获取渔获的行为，在各类水域均属被严格禁止的渔法**，这类行为不仅针对目标鱼，也会波及整个水体的生物群落，且往往危及人身安全。无论生产性还是休闲场景，触碰这类渔法都面临明确的法律后果，没有任何「只是玩玩」的豁免空间。

## 三、受限制的渔具类型

在渔具层面，多地针对网具、钩具作出区分管理。以某些流域为例，常见做法是限制**网目尺寸过小的网具**，以减少对幼鱼的误捕；对钓具则常见限制多钩、串钩、可视锚鱼等对资源影响较大的类型。但「多小算小」「哪些钩型被禁」在具体水域并不统一，实际口径**以当地渔业主管部门的公告为准**。

## 四、休闲垂钓须规避的红线

即便在允许垂钓的水域，钓友也应主动避开与禁用渔法、禁用渔具相关的做法：不使用电力、化学物或爆炸手段；不携带与被禁网具功能相近的工具；不采用明显超出休闲范畴的捕捞装备。**涉及渔具合规性的判断，不确定时一律向当地渔政或农业农村部门确认。**

## 五、发现违规如何处理

若在钓场发现他人使用破坏性渔法，建议以记录线索、向主管部门举报的方式处理，避免在现场与对方发生冲突。举报渠道通常包含当地渔政执法与农业综合执法部门。

> 结语：禁用渔具与渔法守护的是整个水体的生态底线，休闲垂钓应严格远离电、毒、炸及各类破坏性手段，存疑即向官方核实。
