# 夜钓技法

## 一、光线管理

夜钓的光不只要照得见漂，更要**尽量不惊扰鱼**。多数情况下鱼对水面突然的强光照射有明显回避，因此灯光应避免直射水面与窝点。

常见方案有夜光漂、电池电子漂与头灯辅助。电子漂自带光源、读漂直观，适合静水常规钓；夜光漂靠荧光，亮度低、存在感弱，鱼情谨慎时更稳妥。头灯只用于上饵换钩，操作时侧身遮挡，用完即关。岸边可放一盏弱光照明物防踏空，但不宜正对水面。

## 二、钓组的调整

夜间鱼的警惕性通常略低于白日，但视线差要求钓组更耐读、更可靠：

| 调整项 | 建议 | 原因 |
| --- | --- | --- |
| 漂尾 | 选加粗尾或电子漂，目格清晰 | 弱光下细尾难辨 |
| 线组 | 在鱼体允许内略放大 | 夜间易遇不明大体型鱼 |
| 钩饵 | 饵可稍硬稍黏 | 减少小杂鱼骚扰与反复换饵 |

**前提是依据目标鱼大小调整**，不是一味加粗，过钝会漏掉轻口。

## 三、观漂要点

夜间背景单一，漂相反而比白日容易分辨，但干扰也特殊：风浪在无光面更难察觉，需靠漂的稳定基线判断；蚊虫扑灯、水面反光会造成误读。

读漂时可盯住漂尾与黑暗交界处的相对位移，关注「加速下顿」与「异常上顶」这类非自然变化。遇到连续小幅晃动先排除风与水流，确认是鱼口再提。**夜钓节奏宜稳，不宜频繁起竿惊窝**。

## 四、安全与作息

夜钓环境风险高于白日：岸边湿滑、地形不熟、低温与蚊虫都需防范。应结伴出行、穿防滑鞋、备好防蚊与保暖；电子设备多带一组电源，避免电子漂与头灯中途没电。作钓中注意体温变化，后半夜气温通常走低，鱼口也可能随温度起伏。

## 五、常见误区

1. **强光直射水面**：为看清而把灯对准窝点，鱼受惊离底，反而无口。
2. **盲目守底不动**：夜间鱼层同样会随温度变，长时间无口应试探离底。
3. **忽视温度变化**：后半夜降温鱼口转差，仍死守旧法，不如调整水层或收工。
4. **装备电量不管**：电子漂没电后无法读漂，缺乏备用电源会提前结束。

> 结语：夜钓赢在光线克制与读漂稳定，把惊扰降到最低，鱼口往往比白日更干脆。
