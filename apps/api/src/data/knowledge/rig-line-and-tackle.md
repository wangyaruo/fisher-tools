# 线组搭配与竿的钓重

## 一、主线与子线的分工

线组里主线和子线承担不同职责，这一点决定了搭配原则：

| | 主线 | 子线 |
| --- | --- | --- |
| 职责 | 承受整体拉力、传递信号 | 隐蔽、在超载时先断 |
| 选型倾向 | 略粗、略硬、耐磨 | 略细、略软、柔软度好 |
| 颜色 | 有颜色便于观察走线 | 透明或水色 |

**核心原则：子线号数必须小于主线号数**。这样在挂底或大物发力时断的是子线，保住浮漂与主线。常见搭配是主线比子线大 1 至 2 个号。

## 二、结节损耗：最容易被忽略的变量

同一卷线，**打结后的拉力通常只有原丝的六到七成**，不同结法的保持率差别很大。这意味着：

- 不要按线盒上标的**原丝拉力值**估算实际能承受的鱼。
- 换线时优先换掉**打过结的那一段**——比如连接八字环的子线，反复使用后是最脆弱的点。
- 定期剪掉竿稍处的主线 30 至 50 厘米，那里因反复缠绕与打结损耗最快。

**具体拉力值以厂家标注为准**，不同品牌、不同批次差异明显，本知识库不给统一的换算表，因为那样反而会误导。

## 三、竿的钓重

「钓重」指钓竿在标准测试条件下能安全抬起的重量，通常是**安全值而非极限值**。它和实际能钓起多大的鱼不是同一个概念：

- 竿的钓重决定的是**能安全把鱼抬出水面**的能力。
- 实际控鱼能力还取决于**竿的长度、调性、腰力**，以及是否使用失手绳与抄网。

**调性**：软调竿护线但控鱼慢，硬调竿起鱼快但易切线。野钓大个体鱼时，软调配合细线往往比硬调配粗线上鱼率更高。

**关键习惯**：永远带抄网。绝大多数「断线跑鱼」不是线不够粗，而是想把鱼**飞上来**。

## 四、按目标鱼选线的思路

给的是**相对关系**而非绝对号数，请结合本地鱼情调整：

1. **先看最大可能出现的鱼**，而不是平均个体。钓点里有一条 5 斤的鲤鱼，线组就要按 5 斤准备。
2. **再看水的障碍情况**。有水草、树桩、乱石时，鱼进障碍后线组会被磨断，此时宁可选大一号。
3. **最后看鱼的活性**。低温、低氧时鱼发力弱，可以适当减小号数换取隐蔽性与入口性。

> 结论：线组的核心矛盾是「隐蔽性 vs 保险系数」。没有通用答案，只有按当天鱼情做的取舍。
