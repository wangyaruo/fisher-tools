# 黑鱼（乌鳢）习性

黑鱼即乌鳢，是淡水中的伏击型掠食鱼，常潜伏于水草、枯枝与浑浊障碍区，以突袭方式吞食经过的活鱼活虾，对低氧、浑水与浅水的耐受力在常见鱼中名列前茅。

## 水层与栖息

黑鱼不偏好开阔深水，而依托**结构**生存：

- **水草区、藕塘、浮萍下**：隐蔽伏击的主要场所。
- **浅滩与岸边**：幼鱼与亚成体常在近岸浅水活动。
- **浑水与缺氧环境**：靠辅助呼吸器官可直接吞吐空气，在其它鱼难以生存的水体仍存活。

繁殖期亲鱼会护巢，在草洞中盘踞并驱赶靠近的入侵者，此时攻击性极强。

## 与气象条件的关系

| 条件 | 黑鱼表现 | 应对 |
| --- | --- | --- |
| 水温 20 至 30℃ | 活性高、捕食频繁 | 主攻季节 |
| 清晨与黄昏 | 近岸伏击活跃 | 路亚或活饵近岸 |
| 雨后浑水涨岸 | 靠边觅食 | 钓草边、入水口 |
| 低温冬季 | 钻泥或深藏不动 | 基本停口 |

黑鱼对**水温与光线**敏感，强光正午多潜伏不动，晨昏与雨后浑水时最愿出击。

## 觅食机制

黑鱼属伏击型：先在障碍后静止潜伏，待猎物进入攻击距离后短距离爆发突袭，吞饵后即回身拖入草丛。这决定了：

- **动态活饵优先**：挣扎的小鱼、蛙类、缓动拟饵最能触发攻击。
- **落点要贴近结构**：投到草洞、草边、枯枝附近，而非空旷水面。
- **节奏**：停顿多于拖动，模仿受伤猎物的微弱动作。

## 常见误区

1. **在开阔水面硬找**：黑鱼依赖障碍伏击，无结构处概率很低。
2. **中鱼后硬拉**：它常把钩拖进草里，生拉易断线或脱钩，应控制其离开草丛再收。
3. **忽视护巢期攻击性**：繁殖期黑鱼会攻击靠近巢区的物体，此时路亚中鱼率反而高，但需注意生态保护。

> 结语：黑鱼的关键词是**障碍与伏击**——把动态饵精准送到结构边缘，并利用晨昏与浑水的出击窗口。
