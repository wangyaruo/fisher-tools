# 鲫鱼习性

鲫鱼是绝大多数淡水钓点的保底鱼种。它对水温、溶氧与浑浊度的耐受范围都明显宽于鲤鱼、草鱼，因此在其它鱼停口时仍可能有口。

## 水层与迁移

鲫鱼属底层鱼，但并非始终贴底：

- **春秋**：水温适宜时贴底觅食，同时会进入 30 至 80 厘米的浅滩。
- **盛夏正午**：表层水温过高，鲫鱼退到深水区或阴凉处，可能出现「离底」现象，此时钓底无口，可改钓离底 20 至 40 厘米。
- **冬季**：集群于深水、背风、向阳处，活动范围极小，需要主动找鱼而不是等鱼。

## 与气象条件的关系

- **气压**：低气压或气压持续下降时，水体溶氧下降，鲫鱼会向浅水与流水处移动。这是「闷热天要钓浅、钓流水」的原因。
- **温差**：昼夜温差大时水温垂直分层明显，鲫鱼需要频繁调节水层，开口通常偏轻。
- **降水**：小雨天鲫鱼开口往往不错；持续大雨导致水体浑浊、水位骤变时反而变差。

## 觅食偏好

鲫鱼口小，吞饵力度轻，对饵料的**状态**比**味道**更敏感。同一款饵，拉丝过多、雾化过快的状态在杂鱼多的水域会明显吃亏。

常见有效味型：奶香、腥香、谷物香。水温低时偏腥，水温高时偏香。

## 观漂要点

鲫鱼典型的入口动作是**下顿**，幅度通常只有半目到一目。放口信号多为上顶，属试探阶段，不宜抢。

> 结论：鲫鱼的关键变量是**水温分层**与**溶氧**。当这两项都不利时，先换水层，再换饵料。
