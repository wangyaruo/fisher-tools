# 远离高压线

钓鱼相关的人身事故里，触电常年排在首位，而绝大多数触电都发生在高压线附近。原因简单到残酷：**碳素鱼竿导电性能极好**，而它长度普遍在四米以上，加上渔线，触及半径远超直觉。

## 为什么危险被低估

- 多数人以为「竿碰不到线就安全」。实际上高压电在空气潮湿、距离很近时可能击穿空气放电，不需要直接接触。
- 挥竿、换钓位时举着竿走，是触电最高发的两个动作——注意力全在鱼上，忘了头顶。
- 雨天、雾天、竿身沾水后，危险距离进一步放大。

## 可执行的原则

- **选点先抬头**：到达钓位第一件事是环视四周有没有电线，尤其是背后与侧上方——甩竿的方向。
- **把「竿长加线长」当作禁区半径**：这个长度能覆盖到的范围内有线路，直接换地方，不讨价还价。
- **移动时收竿**：换钓位、去洗手、上厕所，竿必须收回或平放携带，绝不竖着走。
- **夜钓加倍小心**：黑暗中根本看不到线，白天没踩过点的位置夜里不去。

## 万一有人触电

先断电、再施救。无法断电时用干燥的木棍、竹竿挑开导电体，**绝不徒手上前拖拽**——连环触电会让一个事故变成两个。随后立即拨打急救电话，烧伤创面不要自行涂抹任何东西。

> 结论：没有一条鱼值得用命去换。高压线附近的「好钓位」不是钓位，是事故现场候选。把抬头看线变成和看漂一样的肌肉记忆。
