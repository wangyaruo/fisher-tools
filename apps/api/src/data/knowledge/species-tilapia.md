# 罗非鱼习性

罗非鱼（俗称非洲鲫）原产热带，在华南已成为江河、水库、养殖塘的常见鱼种。它耐受肥水与低氧，生命力极强，但有一个绕不开的短板——**怕冷**。

## 水温决定一切

- **25℃ 以上**：活性最高，全天抢食，夏季与初秋是黄金期。
- **15℃ 左右**：明显减口，退向深水与向阳处。
- **12℃ 以下**：基本停口，北方难以自然越冬，这也是它主要分布在南方的原因。

## 觅食与钓法

罗非口大、吃相凶，成群进窝后抢食猛烈，漂相以大幅度的下顿与黑漂为主，偶尔出现夸张的上顶。

- **饵料**：偏腥是主线，虾粉、肝味、冻饵都是经典选择；大个体罗非（如奥尼、吉利罗非）对谷物香接受度也高。
- **钓法**：钓底为主；夏季高温天可能离底上浮，底钓无口时改钓离底 20 至 30 厘米。
- **打窝**：腥香颗粒或发酵谷物均可，罗非食量大，窝量可以比鲫鱼重。

## 摘钩要小心

罗非背鳍与鳃盖的硬刺锋利，徒手摘钩容易被扎。用毛巾包握或戴手套，配合摘钩器操作。它吞钩较深，深喉钩不要硬拽，剪线取鱼对鱼的伤害反而更小。

> 结论：钓罗非先看水温。25℃ 以上的晴天用腥饵钓底，是华南夏秋最稳定的出钓策略；水温不够时，与其换饵，不如换时间。
