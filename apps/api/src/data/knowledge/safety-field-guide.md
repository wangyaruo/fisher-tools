# 垂钓安全须知

垂钓事故的共同特征是**后果不可逆**。以下按致死风险排序。

## 一、高压线（最容易被低估）

碳素竿在潮湿状态下是**导体**。碳纤维竿导电率很高，靠近高压线时不需要直接接触就可能发生电弧放电。

**硬性规则**：

- 抛竿前先抬头看，确认头顶与后方没有电力线路。
- 出现「有电但不能钓」的情况就放弃这个钓点，不要试图估算安全距离。
- 阴雨天空气湿度大，击穿距离会显著增大。

## 二、涉水与水中行走

- **不要下水**。绝大多数溺亡发生在「只是想过去看看」的浅水区，水下地形与深坑无法目视判断。
- **警惕水底陡坎**：水库、采砂坑、河道整治后的岸线常见人工陡坎，一步之外可能就是数米落差。
- **穿救生衣**：在船只、浮台、滩涂、消波块区域作业时必须穿，不要因为「水浅」而省略。
- **独自出钓要留行程信息**：告诉家人钓点位置与预计返回时间。

## 三、雷电

- 碳素竿是极好的接闪器。**听到雷声立即收竿离开水边**，躲进封闭建筑物或车内。
- 不要躲在孤立的大树下、空旷滩涂上的临时伞下。
- 雷雨前的短暂好鱼口不值得冒险，气压快速下降时的鱼口正是雷暴临近的信号。

## 四、中暑与失温

这两项在垂钓中都比想象中常见，因为它们发生得很慢，不容易被察觉。

- **中暑**：夏季无遮挡水面紫外线与水汽反射叠加，体感远超气温。备足饮水，避开正午，戴宽檐帽。
- **失温**：冬季水边湿度大且风大，静止垂钓时热量流失快。手部最先失温，进而影响操作。备保暖手套与热水。

## 五、潮汐与涌浪（海钓）

- **矶钓、礁石、防波堤**必须两人以上同行，并佩戴救生衣与防滑钉鞋。
- 关注**涌浪周期**而不只是浪高：长周期涌浪在看似平静时也会突然拍上礁石。
- 涨潮时不要在礁石低处停留，退路会被切断。

## 六、装备与急救

- 竿包、抄网、剪刀放在随手可取的位置，不要堆在岸边陡坡上。
- 随身带创可贴、碘伏与止血带。鱼钩刺入皮肤时，**不要硬拔带倒刺的钩**，从另一端穿出后剪断倒刺再退。
- 手机装防水袋并保持电量，提前存好当地救援电话。

> 底线：任何一次出钓都不值得用生命换。判断不了就撤，鱼明天还在。
