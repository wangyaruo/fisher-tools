# 打窝节奏与补窝

## 一、控窝的核心：让鱼留得住、吃不饱

打窝的目的不是把鱼喂饱，而是建立一个**持续的味型与颗粒供给带**，让进窝鱼有得吃、吃不饱、不愿走。**控窝的本质是控制「供给速率」，使窝点始终处于「有食可觅但不易饱」的状态**。

## 二、初始打窝与续窝的节奏差异

- **初始窝**：一次集中投放，建立味型扩散与落点标记，量以能形成可见诱集为准，不宜一次过量。
- **续窝（补窝）**：以少量、多次为原则，维持窝点浓度，避免一次性大补把鱼惊走或喂饱。

两者的逻辑相反：前者求「立」，后者求「续」。把续窝当成第二次初始窝来打，是最常见的节奏错误。

## 三、鱼情与节奏的对应

| 鱼情 | 节奏策略 |
| --- | --- |
| 生口快鱼、密度高 | 补窝勤、单次少，维持高频诱集 |
| 滑口、警惕鱼 | 补窝极轻或暂停，靠钩饵自然诱 |
| 守底层大鱼 | 初始略重、后续很长间隔少量 |
| 流水 | 补窝频率提高，应对冲刷流失 |

**关键结论**：节奏应随「鱼在不在、吃不吃」调整，而不是按固定时间间隔机械执行。

## 四、何时该停、何时该补

判断看信号而非钟表：

- 有连续正口、鱼口稳定 → 维持当前节奏，不必额外补。
- 口变稀、浮漂信号减少但仍有鱼星 → 轻补少量续窝。
- 长时间无口且无鱼星 → 先怀疑钓点与天气，而非盲目加料。

**补窝手法**宜用铅皮带或轻撒，落点集中、动作轻，避免重砸惊鱼。

## 五、常见误区

1. **越补越有鱼**：过量补窝会把鱼喂饱或惊散，尤其滑口鱼，宁少勿多。
2. **按时间表补窝**：脱离鱼情的时间表无效，应以信号驱动。
3. **死窝就猛补**：死窝多为选点或天气问题，加料通常无效甚至更差。

> 结语：补窝是「续」不是「建」，节奏的主动权应交给鱼口信号，而非预设的时间间隔。
