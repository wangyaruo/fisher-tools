# 浮漂选择与吃铅量

## 一、吃铅量的匹配逻辑

吃铅量指浮漂能压下去的铅重，它决定线组能不能被绷直、信号能不能传上来。匹配的出发点不是「越大越好」或「越小越灵」，而是**线组、水深、风力三者的平衡**。

- **水深越大，所需吃铅越大**。水越深，主线越长，水线自重与水的阻力越容易把线压弯，浮漂信号传到竿尖时已衰减。多数情况下，水深每增加一段，就要相应调大吃铅，才能把整条线绷直。
- **主线越粗，所需吃铅越大**。粗线硬、自重沉，小吃铅的漂压不住，线组会松弛，信号出不来。
- **风浪越大，所需吃铅越大**。风会把线吹弯、把漂压下去，此时需要更重的配铅稳住钓点。

**判断标准**：以「抛得出去、线能绷直、走水能稳住」为底线，在此范围内尽量选小。吃铅越小，往往越灵敏，但前提是线组还能被控制住。

## 二、漂型与适用水情

漂身形状影响下沉速度和稳定性，常见区分如下：

| 漂型 | 特点 | 适用 |
| --- | --- | --- |
| 细长身 | 下行快、信号细 | 底钓、轻口、静水 |
| 枣核型 | 兼顾稳定与灵敏 | 综合野钓、有轻微走水 |
| 短粗身 | 翻身快、抗风浪 | 浮钓、风大、走水明显 |

**核心结论**：漂型选错比吃铅差一点影响更大。风浪天用细长身，漂会被压得乱跳，看不清口。

## 三、目数与观漂

目数是漂尾分段的数量与长度。长尾目数多，行程长，能反映鱼在不同水层的接口；短尾目数少，信号集中，适合抓死口。

- **轻口鱼**：用细尾、目数适中的漂，放大微弱信号。
- **杂鱼多**：用短尾、目数少的漂，过滤碎口，只抓实口。

## 四、常见误区

1. **漂越贵越灵**：灵敏度首先取决于吃铅与线组水深的匹配，贵的漂在错配的线组上也出不来信号。
2. **吃铅越小越灵**：小吃铅在深水或粗线下压不住线，反而信号全丢。
3. **一支漂打天下**：同一支漂很难同时兼顾静水轻口与风浪走水，按水情备两到三支更现实。

> 结语：浮漂是线组的「显示器」，选它先问水有多深、风有多大、线有多粗，再谈灵敏。
