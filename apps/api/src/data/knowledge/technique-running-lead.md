# 走水与跑铅

## 一、走水的成因与程度判断

走水指水流带动浮漂与线组整体位移，使钓点漂移、漂目不稳。常见成因有河道径流、下风口风涌、闸口进出水与暗流。判断程度不必靠仪器，看浮漂走速即可：

| 走水程度 | 表现 | 常规应对 |
| --- | --- | --- |
| 轻微 | 漂缓慢横移，目数基本可读 | 略加铅或钓钝即可 |
| 中等 | 漂持续走水，需频繁回拉 | 跑铅或双铅 |
| 严重 | 漂被整支带走、频繁没入 | 重坠躺底、绷尖子或换静水区 |

**前提是先确认走水而非风引起的假信号**，否则按抗流调法会抹掉真实鱼口。

## 二、跑铅的原理

跑铅的核心是**让铅坠固定、主线在坠中滑动**。

做法是主线从空心铅坠或带孔铅中穿过，铅坠两头的太空豆锁住配重但不锁死主线。鱼咬钩时拖动的是整条主线，而不是先把铅坠拉动再传力，浮漂感受到的是鱼拉动线组的失重信号，因此即便铅很重也能保留一定灵敏度。它把「抗流配重」与「信号传递」拆开处理，这正是跑铅能在急流中使用的根本原因。

## 三、规范做法

- 打开铅坠上方太空豆，留出能让主线顺畅滑动的间隙，否则就退化成死坠。
- **铅重要明显大于浮漂的剩余浮力**，保证坠能稳稳躺底不被冲走。
- 子线宜短，通常十厘米上下，缩短鱼拖动主线到浮漂感知之间的距离。
- 调漂以跑铅后浮漂能立稳为准，不必追求精细目数，重点在抗流与出信号。

## 四、局限与替代

跑铅虽抗流，但铅坠躺底会抬高入口门槛，轻口鱼可能吸不动。它也不是唯一办法：

- 中等走水可先试双铅，上铅锚定、下铅滑动，兼顾稳定与灵敏。
- 急流近岸可用绷尖子，靠竿尖弯曲读信号，免去观漂困难。
- 严重走水处，与其硬抗，不如挪到洄湾、深潭等相对静水区。

**选择顺序应是：先调钝，再跑铅，最后换钓位**，不是一上来就重铅死守。

## 五、常见误区

1. **太空豆不打开**：铅坠被锁死，主线无法滑动，鱼拉动的是铅而非线，信号被坠吃没，等于死坠钓法。
2. **铅太轻抗不住**：跑铅失稳等于没跑，坠被冲走，浮漂照样走水。
3. **子线太长**：线长增加延迟与缠绕，跑铅短子线的意义就丢了。
4. **跑铅万能**：静水轻口时跑铅反而钝，应回常规灵敏调法。

> 结语：跑铅是用配重换稳定，靠活坠留信号，水流退去就该退回灵敏钓法，不必长期带重坠作钓。
