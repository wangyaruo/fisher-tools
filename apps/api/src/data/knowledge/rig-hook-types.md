# 鱼钩钩型与号数

## 一、钩型结构的差异

钩型不同，钩门宽度、钩条粗细、钩尖角度都不同，这些差异决定它能稳稳挂住什么嘴型的鱼。

- **袖钩**：钩条细、钩身轻，入口容易，适合鲫鱼等小个体、轻口鱼。
- **伊势尼**：钩条粗、钩门宽、钩尖内弯，刺入后能牢牢锁住，适合鲤鱼、草鱼等大个体鱼。
- **新关东**：钩条适中、无倒刺常见，摘鱼快，多用于竞技与频率较高的作钓。
- **丸世**：钩柄长、钩尖外撇，适合挂蚯蚓、红虫等活饵，不易脱饵。

**核心结论**：钩型先匹配鱼的「嘴型与发力方式」，再谈大小。大嘴鱼用宽钩门，小口轻鱼用细钩条。

## 二、号数的选择思路

号数是钩的大小，厂家标注不统一，不同品牌同号差异明显，所以**以实物大小判断比看号数更可靠**。给的是相对关系：

| 目标鱼个体 | 钩条倾向 | 选钩思路 |
| --- | --- | --- |
| 小型（鲫鱼等） | 细 | 小号袖钩，重入口 |
| 中型（鲤鱼等） | 中等 | 中号伊势尼，兼顾入口与强度 |
| 大型（青鱼等） | 粗 | 大号粗条钩，重强度 |

**判断标准**：钩门宽度约等于鱼嘴宽度的一半较稳妥。钩太小易脱钩，钩太大挡口、鱼不吞。

## 三、倒刺的取舍

倒刺的作用是防止鱼在挣扎中脱钩，但也带来摘鱼慢、伤鱼、易挂线的问题。

- **野钓守大鱼**：多数情况保留倒刺，增加遛鱼保险。
- **竞技或放流**：常用无倒刺，摘鱼快、对鱼伤害小。
- **有倒刺的钩不要硬掰直**，会改变钩条应力，容易在关键时刻断裂。

## 四、常见误区

1. **钩越大越保险**：大钩挡口明显，鲫鱼等轻口鱼根本不吞，结果是空竿。
2. **号数全国通用**：不同品牌同号钩实物大小差很多，换品牌要先看实物。
3. **倒刺万能**：倒刺只防脱钩不防切线，主线子线强度不够，有倒刺也拦不住大鱼。

> 结语：选钩先定钩型再定大小，让钩门、钩条与目标鱼的嘴型和发力对上，才是根本。
