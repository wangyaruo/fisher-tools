# 抄网、失手绳与岸边配件

## 一、抄网

抄网是把鱼请上岸的最后一环，多数跑鱼不是线细，而是舍不得用抄网。

- **网口大小**：大个体鱼用大网口，鱼头能一次性进网才稳；网口小，鱼在网沿挣扎容易翻出去。
- **网深与杆长**：深水岸高用长柄深网，近岸浅水用短柄即可。
- **网兜材质**：细软的网兜不伤鱼、也不易挂钩；粗硬的网兜摘钩麻烦。

**核心结论**：鱼出水前就备好抄网，等鱼到岸边再找网，往往惊鱼、断线。

## 二、失手绳

失手绳连接竿把与岸上固定物，是野钓大物的保险。

- **作用**：鱼突然发力时放开竿，绳把竿拉住，鱼拖着竿游也不丢装备，还能借绳的弹性卸力。
- **用法**：一端扣竿把，一端固定在岸上结实处。遛鱼到极限时主动撒手，比硬顶断线好。
- **长度**：以能覆盖钓点前方水域为宜，太短卸力范围小，太长易缠草。

## 三、竿架与岸边小配件

- **竿架（炮台）**：把竿架在稳定高度，长时间守钓不累，也避免竿躺地沾泥、被鱼拖走。
- **鱼护**：选深、口大、网眼适中的，鱼在里面少受伤、易存活。
- **子线盒与配件盒**：把不同号数子线、太空豆、铅皮分格存放，换线不慌乱。

## 四、常见误区

1. **抄网是摆设**：想「飞鱼」上岸，遇到大个体必切线或脱钩，抄网才是稳妥收尾。
2. **失手绳只在跑鱼时用**：它本该是预防，等鱼真发力再想起来扣，往往来不及。
3. **配件越省越好**：一个顺手的竿架、分类清楚的配件盒，省下的是现场的慌乱与时间。

> 结语：抄网、失手绳、竿架这些「配角」，决定的是你能不能把钓到的鱼稳稳收上来，而不是只在理论上钓到。
