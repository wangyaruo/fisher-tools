# 夜钓安全

夜钓的鱼口往往更好，但黑暗会放大一切风险。白天能看清的台阶、湿滑处、水边陡坎，夜里都成了隐形陷阱。这一类事故的主因不是技术，而是**看不见与叫不应**。

## 一、识别夜间特有的风险

- **落水**：岸边轮廓消失，脚下判断失误即可滑入水中，且无人察觉。
- **照明盲区**：头灯晃眼会短暂致盲，反而增加踩空概率。
- **失温更快**：夜间气温下降叠加水面湿气，静止时热量流失比白天快。
- **孤立无援**：同伴分散后，呼救声在水面传播范围有限。

## 二、照明装备与用法

- **必备头灯加备用电源**，头灯解放双手，备用电池单独防水存放。
- **用红光模式或弱光观察浮漂**，红光对夜视力影响小，也不惊鱼。
- **不把强光长时间直照水面或同伴面部**，会造成双方短暂失明。
- 钓位四周固定一盏弱光营地灯，用于辨识脚下地形与装备位置。

## 三、防落水措施

- **岸钓也建议穿救生衣**，尤其站在坡岸、礁石、桥墩等边缘区域。
- 在脚下与水边之间留出**至少一步的安全缓冲带**，不坐拥边沿。
- 湿滑处铺防滑垫或固定踩脚点，竿包、饵盒等不堆在临水一侧。
- 行走进出钓位时，**先开灯看清路再迈步**，不在黑暗中凭记忆走动。

## 四、同伴与联络

- **至少两人同行**，并约定每半小时一次互相照面或呼应答。
- 把钓点、预计收竿时间告知家人，手机装防水袋并保持电量。
- 准备一只高频哨，遇险时三短三短三短是通用的求救节奏，比呼喊省力且传得远。
- 约定**失联超时的处置方案**：到点联系不上即报警，不让意外被当成「钓得忘了时间」。

## 五、夜间突发处置

- 遇雷电立即收竿、关灯撤离至封闭车辆或建筑，碳素竿在雷暴中是接闪器。
- 有人落水时，**先抛可漂浮物（竿包、保温箱）再呼救**，不盲目下水。
- 受伤后利用头灯与哨子定位，由同伴陪同撤离，不独自摸黑走动。

> 底线：夜钓安全靠的是「看得见、叫得应、有人陪」。任何一步做不到，就收竿回家，今晚的鱼口不值得冒险。
